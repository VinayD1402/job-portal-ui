# JobFinder - Job Portal

A modern and responsive Job Portal frontend built using HTML, CSS, and JavaScript.

## Live Demo

[View JobFinder Website](https://vinayd1402.github.io/job-portal-ui/)

## Features

* Responsive design for desktop, tablet, and mobile
* Job search by title, location, and category
* Featured job listings
* Company section
* Job details modal
* Job application form
* Newsletter subscription
* Dark and light mode
* Mobile navigation menu
* Smooth scrolling
* User-friendly interface

## How to Run the Project

1. Download or clone this repository.

```bash
git clone https://github.com/VinayD1402/job-portal-ui.git
```

2. Open the project folder.

```bash
cd job-portal-ui
```

3. Open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code.

## Main Functionalities

### Job Search

Users can search for jobs using:

* Job title
* Location
* Job category

### Job Details

Users can click the **View Details** button to see:

* Job title
* Company name
* Location
* Salary
* Required experience

### Apply for Jobs

Users can click **Apply Now** and submit:

* Full name
* Email
* Phone number
* Application message

Currently, the form works on the frontend. Backend and database integration will be added later.

### Dark Mode

Users can switch between dark mode and light mode. The selected theme is stored using browser local storage.
